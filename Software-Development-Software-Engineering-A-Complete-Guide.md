# Software Development & Software Engineering : A Complete Guide

![Software-Developer-Software-Engineer](https://miro.medium.com/v2/resize:fit:4800/format:webp/1*Yn0AhHh5XQimQfolZn9UPA.jpeg)

**Software Development** is the process of development of a Software (website, application, operating system, desktop software, etc.).

**Software Engineering** is the branch of Computer Science that focuses on developing, designing, testing, deploying and maintaining a Software.

In short, **Software Development is the part of Software Engineering**.

---

### SOFTWARE DEVELOPMENT :-

Software Development involves the development of a variety of Software. These software can be developed using Front-End technologies, Back-End technologies or a combination of both (Full-Stack), depending on it’s Architecture. A software developer can be involved in the process of designing, testing and deployment, but the major focus is on the development part, rather than the broader engineering lifecycle.

Let’s explore different types of software in detail :

**Website / Web Application -**

A Website is a collection of mostly Static pages primarily focused on providing information with minimal interactivity.

Example : Wikipedia, News Articles, Personal Blogs, etc.

A Web Application is a collection of Dynamic pages primarily focused on performing tasks and allows user interactions.

Example : Social Media, E-Mails, E-Commerce, etc.

Both software run in a Web Browser and are accessed over the Internet.

**Mobile Application -**

A Mobile Application is a software that runs on Mobile devices. It can be Native Application (Android-only or iOS-only) or Cross-Platform Application (works on both Android and iOS).

Example : Google Camera (Android), FaceTime (iOS), Instagram (Cross-Platform)

**Operating System -**

An Operating System is a software that manages and coordinates the Hardware and Software resources of a Computing device, providing an interface between the User and the Machine, ensuring efficient Resource utilization and enabling the execution of Applications and Programs.

An OS can be Computer-based (Windows, Linux, MacOS, etc.) or Mobile-based (Android, iOS, HarmonyOS, etc.).

**Desktop Software / Desktop Application -**

A Desktop Software or a Desktop Application is a software that is installed and runs directly on a computer. It uses the resources of the operating system and works offline or online (depending on the application).

Example : VLC Media Player, Adobe Photoshop, Visual Studio Code, etc.

So, either you are a Web Developer, App Developer, Game Developer (Website, Application or Desktop Software), Front-End Developer, Back-End Developer, Full-Stack Developer, MERN-Stack Developer, MEAN-Stack Developer, LAMP-Stack Developer, React Developer, Python Developer, etc. etc. etc. … you are still a Software Developer!

Even Salesforce Developers and Shopify Developers are also Software Developers. These are just platform-specific software developers.

Salesforce and Shopify have their own eco-system along with some additional tools and technologies.

Salesforce develops Business and Enterprise Software like Customer Relationship Management (CRM) software, Content Management System (CMS) software, Enterprise Resource Planning (ERP) software, etc.

Shopify develops E-Commerce Software like Online Stores, Integration Software (for payment, shipping, etc.), Order Management Software, etc.

### SOFTWARE ENGINEERING :-

Software Engineering is the process of applying the Engineering Principles to the complete lifecycle of a Software — from it’s initial concept to it’s long-term maintenance.

**Engineering Principles :**

**1. General Engineering Principles (The “Big Three”) —**
- DRY (Don’t Repeat Yourself) — Every piece of Logic should be single and individual representation in the system. No copy-pasting! Make the system easier to update — change it in one place, and it updates everywhere.
- KISS (Keep It Simple, Stupid) — Systems work best if they are kept simple, rather than complicated. Avoid Over-Engineering or un-necessary complex code that others don’t understand. This will reduce bugs and make the code easier for others to read.
- YAGNI (You Aren’t Gonna Need It) — Never add functionality until it is actually required. Developers often waste time building features “just in case” they need them later. Save time & effort and keep the system clean.

**2. Robert C. Martin’s 11 Principles —** Robert C. Martin (often called “Uncle Bob”) introduced a collection of 11 Object-Oriented Design Principles focused on building maintainable and extensible software.

Those principles are divided into 3 categories :

**Class Design Principles (The SOLID Principles) —**

(a) **S**ingle Responsibility Principle (SRP)

(b) **O**pen-Closed Principle (OCP)

(c) **L**iskov Substitution Principle (LSP)

(d) **I**nterface Segregation Principle (ISP)

(e) **D**ependency Inversion Principle (DIP)

**Component / Package Cohesion Principles —**

(a) Release/Reuse Equivalency Principle (REP)

(b) Common Closure Principle (CCP)

(c) Common Reuse Principle (CRP)

**Component / Package Coupling Principles —**

(a) Acyclic Dependencies Principle (ADP)

(b) Stable Dependencies Principle (SDP)

(c) Stable Abstractions Principle (SAP)

**3. Separation of Concerns (SoC) —**

Split the software into distinct sections, each addressing a separate concern — UI, Business Logic, Database Logic, etc.

**Software Development Life Cycle :**

**1. Planning —**

This is the first phase where the project’s goals, scope, timeline, budget, and feasibility are decided. Teams analyze whether the project is technically and economically possible and identify risks early.

Job Profiles Involved :

- Project Manager
- Product Manager
- Business Analyst
- Stakeholders / Clients

**2. Requirements —**

In this phase, detailed requirements are gathered from users and stakeholders. The team documents what the software should do, including functional and non-functional requirements.

Job Profiles Involved :

- Business Analyst
- Product Owner
- System Analyst
- Clients / End Users

**3. Design —**

The design phase defines how the software will be built. This includes system architecture, database design, user interface design, and technology choices.

Job Profiles Involved :

- Software Architect
- System Designer
- UI / UX Designer
- Technical Lead

**4. Development —**

This is the coding phase where developers write the actual code based on the design documents and requirements. Different modules are developed and integrated.

Job Profiles Involved :

- Software Developers / Programmers
- Front-End Developers
- Back-End Developers
- Full-Stack Developers

**5. Testing —**

Testing ensures the software is free of bugs and works as expected. Test cases are executed to verify functionality, performance, and security before release.

Job Profiles Involved :

- QA Engineer
- Test Engineer
- Automation Tester
- Manual Tester

**6. Deployment —**

In this phase, the software is released to the production environment so users can start using it. This may involve installation, configuration, and user training.

Job Profiles Involved :

- DevOps Engineer
- Release Manager
- System Administrator
- Cloud Engineer

**7. Maintenance —**

After deployment, the software is monitored, updated, and improved. Bugs are fixed, performance is optimized, and new features may be added based on user feedback.

Job Profiles Involved :

- Maintenance Engineer
- Support Engineer
- Software Developer
- Operations Team
